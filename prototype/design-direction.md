# Creator Rewards visual direction

An outdoor creator's collection, presented as an interactive product story for a hackathon. Four connected scenes: idea, creator, fan, economics. English presentation; Czech presenter notes. Original illustrative textile artwork, clearly marked as concept rather than Arcade output.

Palette: cloud #edf3f5, ink #193b47, white #ffffff, sea #22776d, signal orange #f36c32, sand #dfcda9. Albert Sans if available locally, otherwise system sans. Large plain-language headlines; left-aligned copy and spacious, asymmetric artwork area. Orange communicates action or a reward, never decorates the artwork as a merchant logo.

Distinctive element: sculptural pillow illustrations carry the creator's landscape motif. Restrained app chrome frames these tangible objects. Product choices change the illustration, basket choices change the economics. No generic analytics dashboard or decorative gradients. Gradients used only to illustrate fabric depth.

Review: avoid the generic cream/serif/terracotta palette. Cloud blue and substantial sans typography fit this product demonstration. No external image or font dependency; presentation works offline. Mobile stacks the composition, keyboard focus is visible, reduced motion is respected.
